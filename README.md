# Personal Portfolio Website

## Overview

This project is a personal portfolio website designed to showcase my skills, projects, and experience as a developer for both Computer Science and Digital Art.
It serves as a central location where employers, recruiters, classmates, and collaborators can learn more about me, view my work, and find ways to contact me.

The website was built as a static website using HTML, CSS, and JavaScript while following best practices for version control with Git and deployment through GitHub Pages.

---

## Features

- Responsive design for desktop and mobile devices
- Home page introducing myself
- Projects page highlighting my work
- Interactive project filtering using JavaScript
- Contact page with professional links
- Clean and modern user interface
- Easy navigation between pages

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Git
- GitHub
- GitHub Pages
